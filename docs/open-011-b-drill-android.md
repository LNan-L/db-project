# OPEN-011 B — Android 手机跨设备恢复演练清单

- 目标：在**安卓手机**上导入 PC 导出的 `.pke.enc`，验证 B 的恢复路径。
- 前提：PC 有网线、手机有流量；两者不在同一局域网。
- 关键限制：手机必须打开 **HTTPS** 地址；普通 `http://IP` 下 `crypto.subtle` 不可用，加密导入会失败。

## 电脑端准备

1. 双击 `启动手机演练-预览.cmd`，等它显示 `http://127.0.0.1:4273`，窗口保持。
2. 双击 `启动手机演练-隧道-localhost.run.cmd`，等它打印 `https://...` 地址，窗口保持。
   - 如果不通，改用 `启动手机演练-隧道-pinggy.cmd`。
3. PC 浏览器打开 `http://127.0.0.1:4273`。
4. 「数据」→ 输入备份口令（≥12 位）→「导出加密备份」。
5. 保存 `.pke.enc`；**恢复码单独保存**，不要和备份文件放同一个目录。
6. 记下加密包 SHA-256（数据面板会显示）。

## 传到安卓手机

- USB 数据线（MTP）拷到 `Download/`；或微信文件传输助手；或网盘。
- `.pke.enc` 是加密的；恢复码不要跟文件一起发。

## 手机端导入

1. 用 Chrome 打开隧道打印的 `https://...` 地址。
2. 如果出现证书/隧道提示，按页面说明继续；确认地址是 `https://`。
3. 打开「数据」。
4. 输入同一个口令，或输入恢复码。
5. 「导入加密备份 / ZIP / Markdown」→ 选手机 `Download/` 里的 `.pke.enc`。
6. 看预览：新增/附件/关系数量；确认写入。
7. 验证：
   - 笔记数量
   - 至少一篇正文
   - 标签/文件夹
   - 双链反向引用
   - 附件
8. 截图 + 记录结果。

## 失败时先查

- 手机打开的是 `http://` 还是 `https://`：必须是 HTTPS。
- Vite 是否报 `Blocked request`：本项目已设 `allowedHosts: true`；确认用最新配置重启。
- tunnel 地址是否过期/被关：重开隧道脚本。
- 口令/恢复码是否正确：GCM 会直接报错，不会静默导入。
- 手机是否已有同 ID 笔记：用新浏览器 profile / 清站点数据；同 ID 会跳过。

## 安全

- 隧道 URL 临时有效；演练完关掉两个窗口。
- 不要把恢复码和 `.pke.enc` 放一起。
- 只在可信网络使用；隧道服务能看到 HTTPS 流量，但备份不会上传，数据只在手机浏览器本地。
- 临时隧道域名不适合长期 PWA 使用；长期需要稳定 HTTPS 域名。
